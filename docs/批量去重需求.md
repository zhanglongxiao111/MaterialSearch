### 智能去重方案

#### 3.2.1 多层次去重策略

**层级 1：完全相同检测（文件哈希）**

- 原理：计算文件 SHA1 哈希值

- 适用：检测完全相同的文件（字节级别）

- 准确度：100%

- 速度：极快

**层级 2：视觉相同检测（感知哈希）**

- 原理：使用 pHash、dHash、aHash 算法

- 适用：检测经过压缩、轻微编辑的同一图片

- 准确度：95-99%（可调节阈值）

- 特点：对光照、色彩、缩放变化鲁棒

**层级 3：内容相似检测（向量相似度）**

- 原理：使用 CLIP 向量计算余弦相似度

- 适用：发现内容相似但不完全相同的图片

- 准确度：可调节（建议阈值 0.95）

- 特点：识别同场景不同角度、相似设计风格

**层级 4：尺寸变体检测**

- 原理：比对宽高比和分辨率

- 适用：识别同图不同分辨率版本

- 判定标准：宽高比差异 < 10%

- 处理策略：保留高分辨率版本

#### 3.2.2 去重工作流程

**上传时实时检测**：

```Plain
用户上传图片    ↓计算文件哈希 → 检测完全相同    ↓ (未发现)计算感知哈希 → 检测视觉相同    ↓ (未发现)提取 CLIP 向量 → 检测内容相似    ↓显示检测结果和相似图片    ↓用户选择处理方式：- 跳过不上传- 替换旧图（保留高分辨率）- 保留两个版本（建立关联）    ↓执行相应操作
```

**批量清理流程**：

```Plain
管理员触发批量去重    ↓扫描整个素材库    ↓按感知哈希分组    ↓识别重复图片组    ↓生成去重报告：- 完全相同：XX 张- 视觉相同：XX 张- 内容相似：XX 张- 可节省空间：XX MB    ↓人工审核确认    ↓批量处理（删除/关联/归档）
```

#### 3.2.3 去重数据结构

**重复关系管理**：

- `is_duplicate` 字段：标记是否为重复图片

- `master_image_id` 字段：指向主图（最高分辨率或最早上传）

- `duplicate_group` 字段：同一组重复图片共享相同 group_id

- `duplicate_type` 字段：标注重复类型（exact/perceptual/similar/scaled）

**查询功能**：

- 查看所有重复组

- 按重复类型筛选

- 显示每组的主图和副本

- 对比图片详情（分辨率、大小、上传时间）
