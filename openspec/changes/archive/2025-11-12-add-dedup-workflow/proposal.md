# Change: 增加素材去重能力

## Why
- 永久库搜索时会出现大量重复素材（同一咖啡厅图片占满一屏），严重影响检索效率和视觉审查体验。
- 历史库缺乏统一的去重手段；现有字段虽然存了 checksum/phash，但没有流程产出“主图 + 副本”标记，更无法让前端自动隐藏重复结果。
- 上传路径上只提示“重复”，但没有自动策略（优先高分辨率、自动跳过），仍需人工判断，效率低。
- 用户希望手动触发批量去重报告，而不是每次上传都被长耗时检测阻塞。

## What
1. **实时精确去重**：上传到永久库时，用 checksum + 文件大小即时判定完全相同素材，默认跳过重复，并在存在不同分辨率时自动保留像素更多的一份。
2. **后台批量去重任务（手动触发）**：
   - 仅针对永久库运行，按“完全相同 → 感知哈希 → CLIP 相似度”三段策略扫描。
   - 生成去重报告（组数、可释放空间、每组主图/副本），并持久化 `duplicate_group` / `master_image_id` / `duplicate_type`。
   - 运行过程中不阻塞上传，完成后供管理员决定处理方式。
3. **搜索结果去重**：永久库搜索默认排除 `is_duplicate=1` 的副本，只展示主图（优先更高分辨率），必要时允许“包含重复”过滤选项；项目库保持原样。
4. **Workspace / 经典 UI 支持**：在 UI 中提供“手动去重”入口与状态提示，仅当选择永久库时可点击；弹回最新报告摘要。

## Impact
- **后端**：扩展上传、搜索、数据库操作与后台任务逻辑；新增/更新 API（启动去重任务、查询报告）。
- **前端**：Workspace/Classic 搜索页需增加手动触发按钮、报告弹窗、以及“包含重复”筛选开关。
- **OpenSpec**：更新 `image-storage`、`upload-to-library`、`search`、`frontend-library-ui` 等规范，约束仅永久库去重、手动触发策略、搜索过滤行为。
