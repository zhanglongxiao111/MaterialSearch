# 多 Agent 协作文档规范

**版本**: 1.0  
**创建日期**: 2026-01-09  
**创建者**: Gemini Antigravity  
**适用范围**: MaterialSearch 项目所有 AI Agent 协作  

---

## 一、核心原则

1. **可追溯性**: 每份文档必须清晰标注来源 Agent 和创建时间
2. **中文优先**: 文件名和内容使用中文，便于人类阅读
3. **统一位置**: 所有协作文档集中存放，便于管理
4. **规范命名**: 文件名包含关键信息，无需打开即可了解内容

---


## 三、文件命名规范

### 基本格式

```
[类型]_[主题描述]_[来源Agent]给[目标Agent]_[日期].md
```

### 类型前缀

| 前缀 | 用途 | 示例 |
|------|------|------|
| `任务` | 分发给其他 Agent 的工作任务 | `任务_重构用户模块_Antigravity给Codex_0109.md` |
| `报告` | Agent 完成任务后的结果报告 | `报告_前端功能对比_Codex给Antigravity_0109.md` |
| `问题反馈` | Bug 报告或问题描述 | `问题反馈_搜索超时_Claude给Antigravity_0109.md` |
| `方案讨论` | 技术方案或架构讨论 | `方案讨论_缓存策略_GPT给Antigravity_0109.md` |
| `交接文档` | 任务中断时的状态记录 | `交接文档_上传模块_Antigravity给Codex_0109.md` |

### Agent 标识

| 标识 | Agent |
|------|-------|
| `Antigravity` | Google Gemini Antigravity |
| `Codex` | OpenAI Codex / GPT |
| `Claude` | Anthropic Claude |
| `Cursor` | Cursor AI |
| `Copilot` | GitHub Copilot |

### 日期格式

- 完整日期: `20260109` 或 `2026-01-09`
- 简短日期: `0109`（当月内使用）

## 五、工作流程

### 1. 任务分发流程

```
发起方 Agent                     接收方 Agent
     │                               │
     ├── 创建任务文档 ──────────────→ │
     │   (任务_xxx_发起方.md)        │
     │                               ├── 阅读任务
     │                               │
     │                               ├── 执行任务
     │                               │
     │ ←───────────────────────────── ├── 创建报告文档
     │     (审核报告_xxx_接收方.md)   │
     │                               │
     ├── 确认完成 ──────────────────→ │
     │                               │
     └── 归档文档                    └──
```

### 2. 文档生命周期

1. **创建**: 放入 `docs/临时沟通/`
2. **活跃**: 协作进行中
3. **完成**: 任务结束后 7 天内
4. **归档**: 移入 `docs/归档/YYYY-MM/`

---

## 六、最佳实践

### DO ✅

- 使用明确的中文文件名
- 在文档开头标注 Agent 和时间
- 引用相关文件时使用相对路径
- 完成任务后及时更新状态

### DON'T ❌

- 不用英文缩写做文件名（如 `task_001.md`）
- 不省略来源 Agent 标识
- 不在文档中硬编码绝对路径
- 不删除协作文档（应归档保留）
