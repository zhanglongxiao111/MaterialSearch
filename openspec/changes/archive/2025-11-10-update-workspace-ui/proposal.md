# Change: 更新 Workspace 前端界面以匹配 design v3

## Why
- 现有 `static/index.html` 在多次功能叠加后布局杂乱（控件溢出、缺少主题/视图切换），与 `.superdesign/design_iterations/materialsearch_3.html` 最新原型差距巨大。
- 设计稿提供了统一的 Workspace 框架：顶部指示当前库范围、左侧分区管理库/项目、中央命令面板+结果瀑布流，并增加了视图切换、主题切换、Tab（搜索/上传/统计）。当前 UI 没有这些体验，难以在项目/永久库之间快速切换。
- 即将推进的项目侧批量上传、统计面板等功能需要可扩展的 shell 来承载；如果不先落地统一 UI，后续功能仍会散落在旧表格布局中。

## What
1. **Workspace Shell 与主题**
   - 顶部应用栏包含 logo、当前范围 chip、主题切换器、快速按钮（打开上传/触发扫描）。
   - 主题支持 `auto/light/dark` 三态并保存在 `localStorage`。
2. **侧边栏与范围管理**
   - 左侧 pill 切换 `permanent/project`，匹配永久库分类列表、项目列表（含“+ 新建项目”占位）。
   - 切换时更新顶栏 chip 与说明文本，并驱动搜索范围 / API 参数。
3. **命令面板**
   - 统一的搜索命令行（主输入 + Top N 下拉 + 搜索按钮），下方含搜索模式 pill（文本/图片/视频/混合）、高级筛选开关、复制路径按钮、视图开关（瀑布流/网格）与缩略图大小滑条。
   - 高级面板支持包含/排除路径输入与快速筛选 chips（例如最近 30 天、授权状态）。
4. **结果区域**
   - 默认瀑布流布局，记录 `data-lib`、匹配度、来源、路径及操作按钮（复制、归档、删除等）。
   - 视图切换时在瀑布流与网格之间切换；缩略图 slider 会调整列数/卡片尺寸。
5. **Tab 导航**
   - Search / Upload / Stats 三个 tab；切换时保留命令面板的显示策略（仅搜索时显示）。
   - Upload/Stats 面板先提供结构化容器与指示文本，为后续批量上传/统计接口预留位置。

6. **数据与统计同步**
   - Sidebar 永久库分类、项目卡片的数量/状态全部读取 `/api/status`、`/api/projects` 实际字段，禁止使用硬编码占位数字。
   - Scope chip、Stats tab 等展示的总量保持与后端一致，刷新后能恢复。
7. **结果详情与图像预览**
   - 搜索结果卡片支持点击打开 overlay，与设计稿一致地展示大图、路径、来源、评分、尺寸、采集时间等数据库字段。
   - 采用 Viewer.js / PhotoSwipe 等标准图片查看库实现缩放、旋转、拖拽、键盘导航，不再手写临时控件。

## Impact
- **代码**：主要变动 `static/index.html`（结构 + 脚本 + 样式），除主题/视图控制外还需引入实时统计 API 调度与 Viewer.js / PhotoSwipe 等第三方库资源，请注意加载顺序与缓存。
- **规约**：更新 `frontend-library-ui` 关于 Workspace Shell、命令面板、结果视图、Tab 的规范描述。
- **用户**：获得统一的视觉体验，明确当前资源范围，并支持搜索、上传、统计等扩展操作。
